## 📜 QUEST LOG

### Pathless Map

機密情報を入力せず、複雑なファイルの受け渡し・加工・格納ルートを整理する導線マップ。

[Repository](https://github.com/Ryohei0Otsuka/pathless-map) /
[Demo](https://ryohei0otsuka.github.io/pathless-map/)

### Staff Guard Map

欠員発生時の人員体制と、業務機能の維持状況を可視化するプロトタイプ。

[Repository](https://github.com/Ryohei0Otsuka/staff-guard-map) /
[Demo](https://ryohei0otsuka.github.io/staff-guard-map/)

### Stuck Map

プロジェクトの詰まりを早めに見つけ、チームで共有するための進行支援ボード。

[Repository](https://github.com/Ryohei0Otsuka/stuck-map)

### Bass Catcher

楽曲からベース音とルート音を検出し、演奏練習を支援するWindows向けデスクトップアプリ。

[Repository](https://github.com/Ryohei0Otsuka/bass-catcher)
